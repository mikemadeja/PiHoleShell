# Example Output

Real output captured from every exported function against a live Pi-hole v6 server, generated by `tools/Update-ExampleOutput.ps1`. Values (query counts, IDs, timestamps, etc.) reflect whatever that specific server had at capture time - the shape of the output is what matters here, not the exact numbers.

Regenerate with:

```powershell
./tools/Update-ExampleOutput.ps1
# or, to also capture the small number of functions with real side effects on a live server:
./tools/Update-ExampleOutput.ps1 -IncludeDisruptive
```
